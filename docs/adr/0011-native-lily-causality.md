# ADR 0011：原版莉莉技能的权威事实与共同播放时间

- 日期：2026-11-07；状态：用户授权实施并实机验证。
- 前提：保留0639996原版角色/装备/命令/召唤管线及Host权威，不恢复Spine/Spirit/Companion输出复制。

## 范围与实施顺序

先闭合一招实际启用追踪的技能：发动→原版选敌→追踪目标上下文→Host命中反馈→原版停止/清理。观测必须包括Host真实非空目标，空目标的两端一致不算选敌通过。

1. 原生Launch/Query/HomingTick/Stop记录同次技能的根、子路径、输入序号、Pawn代次、Host时间、Invoker/Faction及实际目标组件/位置/速度。先证实第一处分叉。
2. 网络身份与UObject池生命周期分开。根技能关联Host激活身份；子技能复用已核Container Entries路径/occurrence。session、地图及Pawn代次变化撤销关联，旧消息不能在返回同名地图时复活。
3. Host记录原版查询的真实结果（显式null与缺记录分开），Client在对应原版查询处使用Host目标，继续原版SetHomingTarget、初始旋转和Homing Tick。候选碰撞不因此开放，EffectApply/Finalize、伤害/死亡/存档结算闸门保持。
4. 查询事实必须先于消费它的原版调用到达；缺事实、身份冲突、目标未就绪不得悄悄重新本地选敌。采用有界预缓冲/帧完成边界。2026-11-08 按 [ADR0015](0015-causal-fence-wait.md)细化超时：未封口只暂停回放，网络断线交传输层；已封口后的必要依赖缺失仍等待并明确失败。
5. 莉莉、目标运动上下文和反馈使用同一Host时间关系。对齐目标组件身份及原版读取的速度；不以Actor位置相同代替目标上下文相同。位置、速度是原版运动的输入，不自行计算追踪轨迹。
6. Host实际停止关联原版技能族并按播放时刻送原版Stop。Client不得以本地碰撞/猜测距离提前决定权威命中结束；原版完成状态、池复用、异步子技能和清理必须审计。

## 证据、缓存与验收

首轮网络关联限定为原版角色Tick命令链中发动的根技能，以及经原版 Spirit Start（0xCF2F00 / 0xCF3090）登记召唤命令来源、稍后在 Spirit 自身命令链发动的根技能；两者包含已证Container路径的同步/异步子技能。Spirit Start 保存原始 CommandAction.Pawn 的输入序号与 Pawn 代次，不能拿 Spirit 发弹时莉莉的最新输入冒充触发输入；不硬编码技能资产。独立Companion AI决策或其他外部系统发动的异步根没有本轮命令身份，不伪装为已关联技能族。它们仍是后续外部原因域，观测保留，不能把本轮通过推广到这些域。目标事实首轮支持普通/动态敌人的稳定Ref与Host实例代次；本机预测玩家/PvP目标不在本轮写入范围。

新Hook通过EXE SHA和原生前缀预检；反射可定位的入口优先用反射。原生计数/有界trace证明调用；重建头只证明声明。Host/Client全流程、移动目标、显式无目标、重复发动/对象池复用、停止清理和往返切图均使用隔离实例验证，保持前台禁操作及本轮存档备份/还原纪律。

事实、关联、轨迹样本按session/地图代次/激活身份有界保存；原版完成、weak失效、离图和离会回收，状态命令显示活跃项、未匹配、超时、回收及fault。只为协议恶意/截断/容量边界增加CTest，不建游戏行为mock。

验收按已知播放延迟对齐两端同一动作，分别记录目标Actor/组件身份、目标位置/速度、原版弹体轨迹、命中反馈、Stop原因及最终清理。保留FrameProbe整帧、播放缓冲和内存/句柄/活跃族计数，不以截图或调用成功代替完整性结论。具体落地和实测写入2026-11-07的新kb。

Spirit 来源缓存只保留 weak Spirit / CommandAction / Pawn；原版重新 Start 覆盖，weak 失效、Pawn 代次变化、Client地图重置/会话重置撤销（Host持续World中尚存的原版召唤来源保留到新Start覆盖，不能因其它座位离图而清除）；上限128，状态命令审计有效来源与调用数。原版 Start 的返回寄存器原样传回；不替代原版召唤、动画、命令队列和发弹。

同一来源的根序号按 seat / Pawn代次 / 原始输入分别累计，不能只保存“最后一次输入”的计数器：不同 Spirit 的延迟命令可以交错。无活跃族且不再被原版召唤来源持有后回收；上限2048。反馈审计记录 Host 事件时间与 Client 实际播放时间，待播 Spawn 的 Stop 同样等待共同时间，避免提前取消尚未显示的特效。

未消费的 Root 声明和 Query 超过共同时间1秒即明确失败，不能常驻直到容量耗尽。会话/地图清理前恢复仍匹配同一激活的原始时间倍率。FxStop 走有界事件等待队列，加载期间依然可以清理已经到时的旧特效。

命中反馈的技能来源优先取已核 Effect Apply/Finalize 最内层的 self，经实际 UObject Outer 链寻找已登记 Ability 激活。碰撞可能发生于独立 Movement Tick，不能只靠 Homing Tick 的栈作用域给反馈贴根身份；Effect 的 To 只证明输出归属，不能当作发动技能。无 Effect 层时才沿用当前 native Ability 作用域，未知 Effect 不借外层技能冒名。Host捕获与Client播放均留带根/时间的trace用于配对。
