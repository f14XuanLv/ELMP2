# ADR 0007：复制因，不复制果（表现归零、结算收窄、删除测试验收）

- 状态：已采纳（2026-10-29）
- 取代：ADR 0006（逐点位机制清单，见 `explore/p7-failed-snapshot-coverage`）在“表现域”上的选择准则
- 相关：`docs/kb/pipeline-facts.md`（管线事实与两次判决实验）、`docs/kb/sync-coverage.md`（P6 覆盖矩阵，仅作回归检查表）

## 背景

P6 与 P7-2 走的是“冻结客户端模拟 → 把模拟产物（动画名、特效 spawn、音效）逐个复制过去”的加法路线；P7-1 走的是“复制命令 + 客户端跑执行层”，但它把复制单位停在命令层、并在 `aecee34` 删掉了 P6 通道。三次实机结论：P6 完整但手感差、P7-1 手感好但完整性与正确性差、P7-2 两头都输。

2026-10-29 的两次判决实验给出了结构性原因（`pipeline-facts.md` §8–§9）：

1. FX 的实际汇点是 `UGameplayStatics::SpawnEmitterAttached/AtLocation`，而 P6 只钩了包装层 `SpawnFX`；Spine 的两个动画通知生成函数、蓝图直调都不经过它。补一条路径就暴露下一条。
2. 带状态的特效（伴随精灵的 `PS_Spirit` 自身发光）在加载时产生，事件通道错过就永远没有；owner 是 `BP_Companion_*` 时连可复制的身份都没有。
3. 关掉 FX 通道并把本地抑制关掉后，客户端**不会**自己产生特效（`localKept=0`）——因为客户端根本没在跑那条链。
4. 让客户端敌人用原版 `AddNewImmediateCommand` 跑同一条 `CA_e2010_Slime_Attack`，特效自己出现（`localKept=1`），且 FX 通道计数为 0。

## 决策

### 1. 三层模型，判据只有一条

| 层 | 谁负责 | 内容 |
|---|---|---|
| 决策 | Host | 输入采样、AI、命中判定、结算 |
| 模拟 | 两端同一套原版 tick | Pawn Tick → 命令队列 → CommandAction 五时间线 → 状态组件 → 动画组件 → 通知 → 粒子 |
| 表现 | 客户端本地生成 | Spine 轨道、动画通知粒子、技能 FX、音效、弹体 |

判据：**它是否改变权威状态？** 改变 → 结算汇点，做减法；不改变 → 表现，本地生成，不复制。

### 2. 复制因，不复制果；因分两层

- 决策源在 Host AI 的对象（敌人 / 动态敌人）→ 复制**命令启动沿**（`ProcessCommand` `0xCB4F00`，`CurrentResult == NONE`）。
- 决策源在玩家输入的对象（莉莉 / 客人座位）→ 复制**输入快照**（`FInputSnapshot`，40 B）。
- 两者都要带**状态集合**（`UStateComponent.ActiveStates` 的类名集合）：命令是决策，状态是命令的累积结果；只复制命令会让客户端状态漂移（实测：动画卡在 `attack_A_fall_loop` 不自愈），后续 `Necessary / Forbidden` 判定也会错。

### 3. 表现通道归零

- 不为任何表现域新增复制通道；现有 Fx / Snd 通道只作临时兜底，域内验证通过后删除。
- 诊断用的钩子（如 `SpawnEmitterAttached` 捕获计数）可以留，但不得作为机制往上加东西。

### 4. 减法只在结算汇点，越窄越好

效果施加（`OnApplyEffect` / `OnFinalizeEffect`）、死亡（`StartDeathProcess`）、存档、交互副作用、AI 激活。逐点拦截、带计数、未知一律 fail closed。

### 5. 验收：删除测试

**关掉该域的复制通道之后，表现还在、且与 Host 一致**，才算接上管线；不在，缺口在模拟层（tick、状态、通知开关），不是通道。

计数器的“重放成功”不算证据——P7-2 就是被自己的计数器骗了。

## 迁移方式

- 单位是“一个域的整体表现”（敌人 → 远程莉莉 → 精灵 → 音效），不是“一种特效”。
- 每域：结算汇点封闭并计数 → 关掉该域复制通道与本地抑制 → 删除测试 → 通过后删通道；不通过记 kb 并在模拟层找缺口。
- 运行时开关用于 A/B 与现场降级：`elmp set fxLocal 1`（表现不复制）、`elmp set animLocal 1`（动画由状态机驱动）。

## 后果

- `native/coop/commands.*`（命令启动沿复制）成为敌人域的基础设施；`Fx` / `Snd` 通道的删除是目标而不是禁忌。
- 需要新增“状态集合快照 + 校正”（无进行中命令且集合不一致时校正），否则动画与命令判定会漂。
- 覆盖矩阵从“逐点位打勾”降级为“回归检查表”，不再作为验收口径。
