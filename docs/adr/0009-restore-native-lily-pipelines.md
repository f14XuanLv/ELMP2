# ADR 0009：恢复已核实的莉莉原版执行链

- 日期：2026-11-04。状态：采纳；实测验收另记，不等于全游戏覆盖。
- 延续 ADR 0002 方法论与需求树 X-1/X-2；收窄 ADR 0008 对原版链路的冻结与结果复制范围。
- 用户反馈：Client 本机受击不自然、魔女伊莱恩普攻魔法球及远程技能特效缺失。基线提交 `e8a1fe7`。

## 依据与约束

补齐原版上下文，让原版执行；只在证实的结算边界做减法。禁止用新增动画/粒子特例替代上游修复，也不能因部分链路未知而把全域冻结当成最终架构。当前快照保留的域须明确其仍是待迁移实现。原版输入并不包含敌人命中、装备或外部状态等全部原因，不能把“输入一致”作为完整性证明。

代码审查已确认：Client 自己座位只写HP、漂移超过150UU时瞬移，未执行Host的原版击退；Host own-seat过滤不能作为外部受击事实的投递策略。Ability私有挂点被错误折算到Pawn，导致Host拒绝附件复制，同时Client把原版生成的PSC隐藏/停用。对象池同一UObject上的两个activation也不能仅靠ObjHandle区分。具体IDA/CUE证据见本轮受击、技能图谱。

## 决定

1. 本机输入、CommandQueue、Movement、Knockback及SpineAnimation继续由原版驱动。Host已接受的击退通过原生LaunchKnockback入口捕获并投递给所属Client；事件包含地图/会话代次、独立序号、可验证的参数和原版所需上下文。曲线与状态类按资产身份重绑定，不传原始内存或UObject指针。不以HP差值猜测击退，不重开伤害/效果/死亡结算入口。
2. 接收方经原版Knockback入口执行，复用技能取消、移动曲线、状态、受击动画和恢复时序；不把本机角色改成冻结副本，不每帧抢写其动画。上下文无法解析须报告失败，不静默选一个动画或向量。
3. 已通过原版Launch生成的Ability，其私有组件/尾迹由同一次原版activation拥有。此来源只有原版一个表现写者：取消对它的全局本地FX抑制与重复网络FX；不能把Ability挂点改挂到Pawn。生命周期由原版Tick/Stop闭合，副作用继续受权限闸门约束。未证明的派生入口保留未知标记，不据此宣布全部粒子覆盖。
4. Ability启动与停止关联到activation，而非仅关联UObject。Host捕获Stop时即锁定对应启动；Client对象复用使旧activation失效，旧Stop不得停止新技能。地图/离开/销毁清理仍执行。
5. 验收包括原版因果链对照与删除测试：禁用该来源重复复制，原版魔法球/弹体尾迹仍出现、结束正确；Host与Client自己的真实受击有一致的击退/恢复过程。计数、瞬间截图、构建通过均不能独立替代这些验收。
6. 容器的子Ability由原版时间线生成，取消对子启动的重复Act。Host确认的子Stop使用不可变根activation、原版Entries索引递归路径及该条目成功启动次数定位；不凭同类对象或空间距离猜配。FFA子可越过根容器结束/对象复用而存活，根映射须保存至整族原版实际结束。Stop请求与原版实际结束分开，原版延迟结束不得提前当成完成。
7. 等待上下文的同owner启动保持原可靠顺序，超时/队列溢出明确结束会话，不能跳过旧启动后继续接收它的子事件。未知时间线路径、身份冲突同样拒绝。追踪弹选敌结果、目标组件速度及异步生成上下文独立记录为未闭合边，不以原版自动生成粒子替代其证明。
8. 本机受击反馈按已证入口继续恢复。HitStop是独立于Knockback的原版反应：Host接受的LaunchHitStop与击退共用同一有序Reaction流，Client用原始duration调用原版入口，校验factor和AdditionalStates上下文，不以HP下降推测，也不自行合并重复启动。色闪只能调用已核纯DamageColorCurve入口，不能广播附带无敌状态的整个HP.OnReceiveDamage；命中音效/FX须区分Host效果结算产生与Client已运行的Ability自有输出，避免双写。各项分别实测，未实现项不得标通过。
9. 命中音/光的临时输出桥仅覆盖有原版来源证明的输出：Effect Apply/Finalize原生作用域，以及PlayerBase接触碰撞绑定函数的exact指针作用域。前者Client永远不结算，后者Client本机相同来源输出需抑制；普通输入/走路/Ability自有音光不纳入own-seat投递。AE_PlaySE以EffectComponent作world context时按当次原版To辨认目标，不折叠成Ability/Invoker。Snd保留Host实际变换（后台图规范化），FX维持现有exact挂点；只有带此来源证明的消息可解析到Client本机Lily。观察不打开权限闸，不凭资源名判断命中反馈。

本轮实现和图谱不得把尚未核实的Spirit出现/消失、全部Notify、动画混合、世界命中FX和所有Boss标成已完成。
